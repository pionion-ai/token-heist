how to readthe HUD

Everything on screen is a real number from Claude Code, dressed up. Nothing is invented to look busy.

  • Heat◆◆◆◇◇Your context window. One diamond per 20% used. The fifth one pulses, and you know why.
  • RadarSweeps while Claude works. Every tool call is a blip: teal for a read, pink for an edit, orange for a shell command.
  • The flamingoActs out what Claude is doing: thinking, reading, pecking at an edit, running, surfing the web, celebrating when the job is done.
  • CrewHelper agents are chicks. They trot while they are out, and phone you when they are back with a report.
  • The StashEvery Claude Code command as a card. Search by what you want (“undo”, “cost”), pin favourites, level up as you use them.
  • MapA tower per folder Claude has touched. Taller is busier, pink means edited, the pin is where Claude is now.
  • 5H and week dialsYour usage limits as Claude Code reports them. They turn red and throb from 90%.
  • RadioDrives Spotify or Apple Music, and keeps a chart of how many lines you shipped to each song.
  • WipeoutA turn that dies on a rate limit or a server error. A single failed command only makes the flamingo stumble.
  • Game overYou typed /exit. Here are the session's totals. Go and see your family.

four steps tothe job

  1. Download TokenHeist-1.0.0.dmg, open it, and drag Token Heist to Applications.
  2. Open it and click a folder. That is where Claude will work.
  3. Set the Loadout: model, effort and permission mode.
  4. Press Start and type a prompt, the way you always do.

tip-off:before you go in

  • You need Claude Code installed and signed in. Without it the app opens as a plain terminal.
  • The app makes no network connections. No account, no analytics, no update checks.
  • Your own Claude settings files are never read or changed.
  • macOS will ask before the radio controls Spotify or Music. Say no and everything else still works.
